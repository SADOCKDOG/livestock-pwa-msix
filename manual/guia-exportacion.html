2. Generacion PDF & DocumentViewer (Patron Comun)

2.1 Nunca usar window.open / window.print en Capacitor Android

[REGLA OBLIGATORIA] En Capacitor Android WebView, window.open() y window.print() SIEMPRE fallan. Usar DocumentViewer (componente full-screen con iframe sandbox).

2.2 DocumentViewer — Componente Unificado

  • Ruta: components/document-viewer/ (Web Component )
  • Entrada: HTML string o URL blob/pdf
  • Botones: Compartir (Web Share API nativo), Imprimir (nativo Android/iOS/Print), Descargar, Cerrar
  • Funciona en: PWA, Capacitor Android, Electron, Navegador desktop
  • Iframe sandbox: allow-scripts allow-same-origin allow-forms allow-downloads

3. Exportacion Excel Multi-hoja (Solo Premium)

3.1 InformesView.exportExcel()

  • Disponible en InformesView (boton "Exportar Excel" en header, solo si Premium)
  • Genera una hoja por sub-tab activa de la categoria actual
  • Incluye hoja "Resumen" con KPIs principales de la categoria
  • Cabeceras con filtros Excel + formato tabla nativo
  • Nombrado: INFORMES_{CATEGORIA}_{SUBCAT}_{YYYYMMDD}.xlsx

3.2 Estructura Hoja

  • Fila 1: Titulo informe + Fecha generacion + Finca
  • Fila 2: Filtros aplicados (si hay)
  • Fila 3: Cabeceras tabla (con autoFilter: true)
  • Datos: Filas completas con tipos nativos (number, date, string)
  • Ultima fila: Totales / Promedios (segun columna)

3.3 Ejemplo: Export CoMer (Comercializacion)

Hoja 1: Resumen KPIs | Hoja 2: Ventas Carne | Hoja 3: Entregas Leche | Hoja 4: Compradores | Hoja 5: Transportistas | Hoja 6: Contratos | Hoja 7: Albaranes/Facturas | Hoja 8: KPIs Financieros

XML REGA

5. Exportacion XML REGA / SIA / PIGGAN

5.1 Declaracion Censal XML

  • Wizard Censo > Paso 3 > Boton "Exportar XML"
  • Esquema: ComunidadesService.getEsquemaCensalXML(ccaa)
  • Incluye: REGA, NIF/CIF titular, Provincia, Municipio, Tabla Especie|Hembras|Machos|Total
  • Firma digital: Pendiente (requiere certificado FNMT en dispositivo)

5.2 Pedido Crotales XML

  • Wizard Crotales > Paso 2 > Boton "Exportar XML"
  • Destino: SIGGAN (Andalucia) / BADIGEX (Extremadura) / SIA / PIGGAN segun CCAA finca
  • Incluye: Titular, Explotacion, REGA, ADSG, Material (especie, tipo, cantidad)

5.3 Notificaciones REGA XML

  • Generado automatico en NotificacionesREGA.enviar() (Gap 11)
  • Destino: CEBO/ENGORDE derivado de Movimientos.esDestinoCebo()
  • Tipo identificacion: Completa (EID+Visual) vs Matadero (Visual REGA)
Compartir

6. Web Share API (Compartir Nativo)

  • Disponible en DocumentViewer (boton Compartir) y InformesView (boton Compartir)
  • Usa navigator.share({title, text, url/files}) - nativo Android/iOS
  • Fallback si no soportado: DocumentViewer muestra boton "Descargar" + "Copiar enlace"
  • En Android: Abre share sheet (WhatsApp, Email, Drive, Bluetooth, etc.)
  • En iOS: Abre share sheet nativo
  • En Desktop PWA: Abre share del navegador / clipboard

6.2 Compartir Archivos (PDF/Excel/ZIP)

// Ejemplo DocumentViewer.compartirPDF()
if (navigator.canShare && navigator.canShare({files: [pdfFile]})) {
  await navigator.share({
    title: 'Albaran Leche',

} else {
  // Fallback: descargar + toast "Archivo descargado. Usa 'Compartir' del sistema."
}
