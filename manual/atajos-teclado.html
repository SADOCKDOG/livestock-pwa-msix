3. Accesos Rapidos Especiales

3.1 Bento Grid Dashboard (12 Accesos)

Tap en cada tarjeta = Accion directa (abre wizard correspondiente):

  • Peso (Naranja) -> Wizard Pesaje
  • Ordeño (Azul) -> Wizard Ordeño (solo flag LECHE)
  • Entrega Tanque (Azul) -> Wizard Albaran Leche (solo flag LECHE)
  • Albaran Leche (Azul) -> Wizard Albaran Leche (solo flag LECHE)
  • Tratamiento (Rojo) -> Wizard Tratamiento
  • Vacunacion (Rojo) -> Wizard Vacunacion
  • Celo/IA (Rosa) -> Wizard Celo/IA
  • Parto (Rosa) -> Wizard Parto
  • Gasto (Gris) -> Wizard Gasto
  • Censo Anual (Verde) -> Wizard Censo
  • Crotales (Verde) -> Wizard Crotales
  • Guia Movimiento (Verde) -> Wizard Guia

3.2 Widget-Link-Btn Neon (Rebaños / Zonas / Patrimonio)

Botones accion contextual en cards (neon style):

  • Tratamiento -> Wizard Tratamiento (pre-selecciona rebaño/zona)
  • Consumo -> Wizard Consumo Silo (pre-selecciona rebaño/zona)
  • Gasto -> Wizard Gasto (pre-selecciona rebaño/zona, categoria Alimentacion)
  • Mover -> Wizard Movimiento / Rotacion (pre-selecciona origen)

3.3 Busca Universal (Command Palette)

  • Desktop: Ctrl + K
  • Movil: Long press en buscar (lupa header) o swipe 3 dedos abajo
  • Busca: Animales (crotal/nombre), Rebanos, Zonas, Tratamientos, Gastos, Compradores, Contratos, Documentos, Ajustes
  • Acciones directas: "Nuevo Animal", "Nueva Finca", "Exportar Cuaderno", "Cargar Demo"
Accesibilidad

4. Accesibilidad & Navegacion Teclado Exclusiva

  • Tab Order: Logico: Header -> Nav Principal -> Contenido -> Footer -> Modals
  • Focus Visible: Outline neon (--c-neon-blue/--c-neon-green) en todos los elementos interactivos
  • Skip Link: "Saltar al contenido principal" (primer Tab, visible al focus)
  • ARIA: Roles, labels, live-regions en alertas, carruseles (aria-rosette), modals (dialog)
  • Reducir Animaciones: Ajustes > Tema > "Reducir animaciones" -> Desactiva transiciones, gauge animaciones, pulsing badges
  • Alto Contraste: Ajustes > Tema > "Alto contraste" -> Colores semanticos mas saturados, bordes mas gruesos
  • Tamano Fuente: Ajustes > Tema > Slider tamano (Pequeño / Normal / Grande / Muy Grande) -> rem base scaling
