Identificacion

2. Identificacion Animal — Crotal, Razas, Tipos

2.1 Formato Crotal

  • SITRAN: ES + 12 digitos (ej: ES123456789012) - validacion tiempo real dorada/roja
  • ISO 11784: 15 digitos completos (pais + especie + explotacion + animal) - equino microchip implementado
  • DIB/Pasaporte: Para movimientos intracomunitarios / exportacion
  • Tipo Identificacion: Completa (EID + Visual) vs Matadero (Solo Visual REGA)

2.2 Catalogo Razas FEGA Oficial (163 razas, DB v16)

  • Filtrado dinamico por especie (Vacuno, Ovino, Caprino, Porcino, Equino...)
  • Clasificacion: 1001 (Autóctona de fomento), 1002 (Autóctona), 1003 (Integrada), 1004 (Exótica)
  • Grado amenaza: Critico, En peligro, Vulnerable, No amenazada
  • Select actualiza al cambiar especie en Wizard Animal / Rebaño

2.3 Tipos Explotacion REGA (RD 787/2023)

Selector obligatorio en Wizard Rebaño (Paso 2) y Wizard Finca (Paso 1). Cargados desde ComunidadesService segun CCAA:

  • Andalucia (SIGGAN): Tipos especificos Junta Andalucia
  • Extremadura (BADIGEX): Tipos especificos Junta Extremadura
  • Otras CCAA: Via ComunidadesService.getTiposExplotacion(ccaa)
Movimientos

3. Movimientos Oficiales & DIMOE

3.1 Movimiento Oficial Obligatorio (Trigger: Venta Masiva Carne)

Al completar Wizard Venta Masiva, se genera AUTOMATICAMENTE:

  • Tipo: Salida
  • Motivo: Matadero
  • REGA Origen: Finca activa (validada)
  • REGA Destino: Comprador (validado formato ES+12, tipo operador en {matadero, operador_comercial, tratante, cebadero})
  • Tipo Operador Destino: SIGGAN/BADIGEX
  • Explotacion Contraparte: Nombre comprador
  • Numero Guia: Guia oficial (entrada manual Paso 2 Venta Masiva)
  • Especie + Num Animales + Crotales: 15 digitos ISO 11784 por animal
  • Transportista: ID, Nombre, Matricula, ATG vigente, Desinsectacion vigente
  • Fecha: Fecha sacrificio (Paso 2)
  • CCAA: segun finca origen
  • Estado Tramite: 'presentado'
  • Notas: 'Venta comercial {ALBARAN} · DIMOE DIMOE-{ALBARAN}'

3.2 DIMOE — Documento Identificacion Movimiento Orden Expedicion

  • Generado AUTOMATICO al cerrar Venta Masiva
  • Tipo documento: dimoe en documentos_legales
  • Numero: DIMOE-{NUMERO_ALBARAN}
  • Incluye: ICA, Guia, Comprador, Transportista, Veterinario autorizador, Animales (crotales)
  • Imprimible via DocumentViewer / PDF

3.3 Validaciones Bloqueantes Movimiento Oficial

  1. REGA destino formato valido (ES + 12 dig)
  2. Transportista con ATG vigente + Desinsectacion vigente (no vencida)
  3. Comprador tipo operador en {matadero, operador_comercial, tratante, cebadero}
  4. Contrato activo vigente (carne)
[BLOQUEO] Si cualquiera falla -> Wizard Venta Masiva NO permite avanzar al Paso 5. Errores especificos por campo.
Lacteo

4. Paquete Lacteo Completo (Letra Q, INFOLAC, Controles)

4.1 Letra Q (Registro General Agentes Sector Lacteo - MAPA)

  • codigo_letra_q: Formato T-PP-NNNNN (ej: E-41-00123) - validacion MAPA
  • Aplicable a: Tanque, Cisterna, Muestra
  • tipo_movimiento_letra_q (7 tipos RD 989/2022): explotacion_a_cisterna, explotacion_a_rechazo, explotacion_a_establecimiento, cisterna_a_cisterna, cisterna_a_rechazo, cisterna_a_establecimiento
  • estado_letra_q (4 estados): pendiente, comunicado, rechazado, exento
  • fecha_limite_comunicacion_letra_q: Calculo automatico MotorLacteo segun tipo agente destino
  • Recibo Letra Q: Identificacion productor, Codigo explotacion, Fecha/hora, Litros, Operador, Muestra

4.2 INFOLAC (Declaracion Lactea Oficial)

  • Estado tramite: borrador / presentado / validado / error
  • Fecha presentacion, Numero registro, Acuse recibo
  • Numero INFOLAC finca (configurable en Wizard Finca Paso 2)
  • Documento legal tipo infolac_declaracion generado auto en Albaran Leche Wizard
  • Contrato lacteo obligatorio 1 ano minimo (tipo explotacion leche/mixto)

4.3 Controles Lechero Oficiales DHI

  • Organismo control, Fecha, Media rebaño: Litros, Grasa%, Proteina%
  • Integrado en ExplotacionLacteaView sub-tab Control
  • Exportable cuaderno digital (seccion complementaria)

4.4 Calidad Leche (Umbrales por Especie/CCAA)

  • ComunidadesService.getUmbralesCalidadEspecie(ccaa, especie) -> grasa_min, proteina_min, germenes_max, somaticas_max
  • ComunidadesService.evaluarCalidadLecheEspecie -> Bloqueante/Alertas semaforo
  • Aflatoxina M1 (Plan PIVCA): Metodo kit_rapido / ELISA / HPLC
  • Inhibidores in situ: no_realizada / conforme / no_conforme
  • Laboratorios oficiales por CCAA (getLaboratoriosLeche)

4.5 Precios Referencia (Recalculo Vivo Albaran Leche)

ComunidadesService.PRECIO_EXTRACTO_SECO_REF: precio_base_referencia, precio_por_punto_extracto, tasa_INLAC_defecto

Cuaderno

6. Cuaderno Digital RD 787/2023 — Exportacion SIGGAN/BADIGEX

6.1 8 Secciones CSV Obligatorias

  1. TRATAMIENTOS — Fecha, Animal, Producto, Dosis, Via, Veterinario, Retiro carne/leche, Lote, Receta
  2. VACUNACIONES — Fecha, Animal/Rebaño, Vacuna, Lote, Veterinario, Dosis, Via, Proxima revacunacion
  3. CENSO_ANUAL — Fecha referencia, Especie, Categoria, Cabezas, REGA, Certificado
  4. CROTALES — Fecha pedido, Especie, Tipo, Cantidad, ADSG, Veterinario, Estado
  5. MOVIMIENTOS — Fecha, Tipo, Origen/Destino REGA, Animales (crotales 15d), Guia, Motivo
  6. SANEAMIENTOS — Fecha, Tipo (TB/BRU/LEUCO/IBR/PARA), Rebaño, Animales, Resultado, Veterinario, CCAA
  7. FITOSANITARIOS — Fecha, Parcela, Producto, Dosis, Plazo seguridad, Apto comercializacion, Operador
  8. AGENDA — Fecha, Tipo, Titulo, Descripcion, Prioridad, Estado, Recordatorio (seccion complementaria)

6.2 Validacion Pre-Flight (Bloqueante)

Ver Modulo 06, Seccion 4.2. Exportacion BLOQUEADA si falla: REGA, ADSG, NIF, Lotes medicamentos, Crotales 15d, Guias oficiales, REGA destino.
