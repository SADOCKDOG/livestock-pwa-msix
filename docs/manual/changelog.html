v4.10

v4.10.x — Agosto 2026 (Actual)

v4.10.4 — 2026-08-29

  • Compra del soporte inaccesible: En el build Premium (FREE_MODE=false) comprarSoporte() era un stub que solo mostraba "se compra desde la version de la tienda", asi que el soporte no se podia contratar justo en el unico build que se publica.
  • Motor de compras activo en build Premium: Se conserva la app desbloqueada y se registra el producto de soporte contra Google Play.
  • Compra de soporte regalaba Premium: El callback verified() no distinguia producto; ahora filtra por id y sincroniza la licencia de soporte.
  • La licencia comprada era invisible: Transaction.products es {id, offerId}[], no un array de ids; buscarla con indexOf() devolvia siempre -1, asi que ningun recibo se reconocia y una suscripcion activa seguia dando "No se encontro ninguna licencia".
  • La compra no llegaba a abrirse: comprarSoporte() pasaba el Product a store.order(), que espera una Offer; el plugin mandaba productId=null y Google respondia "Product not registered: null". Ahora se pide la oferta con getOffer(), igual que en la compra Premium.
  • Cache-busting desincronizado: los 123 scripts de index.html seguian en ?v=6.74 con el service worker en 6.77.
  • Fallo de compra anunciado como exito: store.error() trataba el codigo 6777003 (ErrorCode.PURCHASE, "la compra fallo") como "ya comprado": cualquier fallo desbloqueaba Premium y mostraba "Compra Premium restaurada". Ahora solo se detecta por el texto del error, se distingue el producto y un fallo real se muestra como fallo.

Notas de Migracion & Compatibilidad

Migracion v3 → v4 (Oct 2025)

  • No migracion automatica datos v3 (Cordoba/localStorage diferente).
  • Exportar JSON v3 -> Importar v4 (Ajustes > Backup).
  • REGA/CEA por finca (antes global).
  • Flags leche/carne por finca (antes "modo hibrido" global).

Version Code Android (Play Store)

  • v4.10.4 -> versionCode 525.
  • v4.10.2 -> versionCode 524.
  • v4.10.1 -> versionCode 523 (publicada en Prueba cerrada - Alpha).
  • Incremental por build: Private/build-and-upload.ps1 auto-incrementa.
  • Solo variante FREE en Play (codigo premium incluido, flag runtime).

PWA / MSIX Versioning

  • PWA: livestock-manager.pages.dev -> deploy via scripts/build.ps1 (main:/docs).
  • MSIX: Microsoft Store -> mismo versionCode Android o independiente.
  • Build FREE incluye todo codigo Premium (desactivado por flag).
