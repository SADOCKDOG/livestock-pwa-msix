Guia Rapida: Inicio en 5 Minutos

Primeros pasos: Finca, Animales, Produccion, Sanidad, Comercializacion

Inicio

Paso 1: Crear/Configurar Finca (1 min)

  1. Abrir app -> Ajustes (engranaje header)
  2. Asistente Configuracion -> Cargar Demo CHAMORRO (opcion rapida con datos reales)
  3. O Wizard Nueva Finca: Nombre, Propietario, REGA (ES+12 dig), CCAA, Superficie
  4. Activar Flag LECHE (si ordeño/entregas) y/o Flag CARNE (si pesajes/ventas)
  5. Guardar -> La app recarga navegacion segun flags activos
[NOTA] En FREE solo 1 finca. En PREMIUM (compra unica premium_unlock) fincas ilimitadas.
Animales

Paso 2: Dar de Alta Animales (1-2 min)

  1. Ir a Ganaderia -> Submodulo Animales (carrusel naranja)
  2. FAB + Nuevo -> Se abre Wizard Animal full-screen (10+ secciones)
  3. Identificacion: Crotal ES+12 dig (validacion dorada/roja tiempo real), RFID opcional
  4. Basicos: Nombre, Sexo (H/M/C), Fecha nacimiento, Especie, Raza (catalogo 163 FEGA)
  5. Rebaño/Zona: Asigna a rebaño existente o crea nuevo (Wizard Rebaño 5 pasos)
  6. Origen: Nacimiento / Compra / Importacion (selector oficiales ComunidadesService)
  7. Guardar -> Animal aparece en lista con badge estado Activo (verde)
[CAPTURA] guia-inicio-wizard-animal.png Wizard Animal seccion Identificacion con validacion crotal dorada
Produccion

Paso 3: Registrar Produccion (1 min)

FAB contextual cambia segun flags: "Registrar Produccion" (ambos) / "Registrar Pesaje" (carne) / "Registrar Ordeño" (leche)

Si Flag LECHE activo:

  1. FAB Registrar Ordeño -> Wizard Ordeño (3 pasos)
  2. Paso 1: Fecha, Turno AM/PM, Tanque destino (Letra Q), Temperatura
  3. Paso 2: Tabla hembras activas rebaño lechero -> input litros por animal (total en vivo)
  4. Paso 3: Resumen + Balance tanque proyectado -> Guardar
  5. Auto: Genera produccion_leche + balance_lacteo entrada + actualiza temp tanque

Si Flag CARNE activo:

  1. FAB Registrar Pesaje -> Seleccion Individual o Lote
  2. Individual: Animal, Fecha, Peso (kg), Rebaño, Zona
  3. Lote: Rebaño, Fecha, Multiples animales con peso individual
  4. Auto: Calcula GMD, actualiza historial, genera evento registro_eventos tipo pesaje
Sanidad

Paso 4: Registrar Tratamiento / Vacunacion (1 min)

Tratamiento (Wizard 3 pasos):

  1. Ganaderia -> Sanidad (purpura) -> Tratamientos -> + Nuevo Tratamiento
  2. Paso 1: Animal/Rebaño, Producto, Lote (obligatorio), Via, Dosis, Veterinario+Colegiado+NIF, Receta
  3. Paso 2: Dias retiro CARNE, Dias retiro LECHE -> Auto-calcula supresion
  4. Paso 3: Confirmacion con alerta supresion visible (Rojo LECHE / Verde Lima CARNE)
  5. Auto: Actualiza animal prohibidoLeche/Carne, emite EventBus -> alertas Dashboard en vivo

Vacunacion (Wizard 2 pasos):

  1. Sanidad -> Vacunaciones -> + Nueva Vacunacion
  2. Paso 1: Animal/Rebaño, Vacuna, Lote, Via, Veterinario+Colegiado, Programa ADSG (oficial/voluntario)
  3. Paso 2: Proxima revacunacion (auto +365d), Recordatorios 30/15/7/1 dias
[CRITICO] Alertas Supresion SIEMPRE visibles (rojo leche, verde lima carne) independientemente del flag de explotacion. Bloquean Venta Masiva y Albaran Leche.
Comercializacion

Paso 5: Venta Masiva Carne / Albaran Leche (1-2 min)

Venta Masiva Carne (Wizard 5 pasos - Solo Flag CARNE):

  1. Comercializacion -> CARNE (verde lima) -> Venta Masiva
  2. Paso 1 Aptitud: Selecciona animales activos (check supresion, edad minima, DIB, gestacion >90d)
  3. Paso 2 Trazabilidad: Fecha sacrificio, Matadero, ICA, Guia sanitaria, Declaracion fitosanitaria 180d
  4. Paso 3 Economicos: Peso vivo, Peso canal (verde), Precio /kg canal (oro), Transporte, Matanza
  5. Paso 4 Liquidacion: Comprador activo (REGA destino valido), IVA/Retencion (contrato), SEUROP
  6. Paso 5 Logistica: Transportista (ATG+desinsectacion vigente), Veterinario autorizador (nombre+colegiado)
  7. FIN: Auto genera DIMOE, Movimiento oficial SIGGAN, Albaran PDF, Factura PDF, Estado animal = VENDIDO

Albaran Leche (Wizard 2 pasos - Solo Flag LECHE):

  1. Explotacion -> LACTEA (azul) -> Albaran Leche
  2. Paso 1: 25+ campos normativos (fecha, volumenes, cisterna, temp, Letra Q, inhibidores, contrato, CCAA...)
  3. Paso 2: Analitica (grasa, proteina, somaticas, aflatoxina M1) -> Recalculo precio extracto seco en vivo
  4. Validaciones: MotorLacteo (temp, stock, inhibidores) + Letra Q + Supresion rebaño + Calidad CCAA
  5. FIN: comercializacion_leche + analiticas_leche + balance_lacteo salida + INFOLAC + PDF
