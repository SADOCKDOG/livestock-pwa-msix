Base de Datos Demo: CHAMORRO

Todas las capturas utilizan la finca demo "Ganadería CHAMORRO (DEMO)" precargada con datos reales de Andalucía (Huelva/Almonte) y Extremadura (Badajoz/Cáceres):

3 Rebaños: Vacas Frisonas (leche), Terneros Cebo (carne), Ovejas Merinas (carne)
8 Animales: 3 vacas, 2 terneros, 3 ovejas con crotales ES 12 díg
4 Zonas: 86 ha con UGM/ha, código PAC, distancia agua
3 Compradores: Cárnico, Lácteo, Híbrido (Extremadura)
2 Transportistas: Camión + Cisterna (ATG, desinsectación, bienestar)
2 Contratos: Carne (CT-2026-001) + Leche (CT-2026-002, INFOLAC)
Producción: Pesajes, ordeños, entregas tanque con analíticas laboratorio
Sanidad: Tratamientos con supresión, vacunaciones ADSG, botiquín FEFO
Reproducción: Celo, IA, diagnóstico, parto con vinculación madre-cría
Comercialización: Ventas carne (DIMOE), entregas leche, albaranes, facturas
Informes: 52/55 guías ExPro, 40/42 CoMer, 36/38 GeGan validadas PWA

Carga la demo desde Ajustes → Asistente Configuración → Cargar Demo CHAMORRO para replicar exactamente las capturas.

Modo de Explotación: Dos Flags por Finca

No existe "modo híbrido global". Cada finca tiene sus propios flags independientes:

Flag LECHE

  • Habilita: Ordeño, Tanques, Balance Lácteo, Albarán Leche, INFOLAC, Controles DHI
  • KPIs: Litros, MOFA, Grasa/Proteína, Extracto Seco, Células Somáticas
  • Alertas: Supresión LECHE (rojo), Inhibidores, Aflatoxina M1

Flag CARNE

  • Habilita: Pesajes, ICA Tandas, Venta Masiva, DIMOE, Guías, SEUROP
  • KPIs: Peso Canal, Rendimiento, GMD, Coste/kg Ganancia, Margen Neto
  • Alertas: Supresión CARNE (verde lima), Periodo Seguridad Fitosanitario

Configuración: Ajustes → Finca Activa → Editar → Modo de Explotación (checkboxes independientes Leche / Carne)
