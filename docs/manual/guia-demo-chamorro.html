4. Pruebas Clave para Replicar Capturas Manual

4.1 Dashboard & Ganaderia

  • Dashboard: KPIs lacteos (MOFA, precio, extracto seco, somaticas semaforo), Bento Grid 12, Alertas supresion rojas/verdes lima
  • Ganaderia Carrusel: 5 tabs (Animales naranja, Rebanos azul, Patrimonio ambar, Zonas verde, Sanidad purpura) - Patrimonio solo si flag CARNE

  • Zonas: Alerta sobrepastoreo Bento rojo animada (Cercado Cebo 2.0 UGM/ha), boton Rotar

4.2 Explotacion & Produccion

  • ExPro carrusel 11 tabs: EXPRO, LACTEA, SILOS, FITOSANITARIOS, FINANZAS, PROVEEDORES, TRAMITES + 4 wizards
  • Lactea 5 sub-tabs: Dashboard (tanques gauge, KPIs, analitica semaforo, alertas MotorLacteo), Tanques, Control, Balance, Graficos (5 Chart.js)
  • Wizard Ordeño 3 pasos: Fecha/Turno/Tanque/Temp -> Tabla hembras litros -> Resumen balance tanque
  • Wizard Albaran Leche 2 pasos: 25+ campos normativos -> Analitica + recalculo precio extracto seco vivo
  • Tanques: Gauge circular stock% clickeable (recalibracion animacion SVG 0%->CAL->real)
  • Silos: Gauge SVG animado, autonomia dias (consumo real 30d), alertas <15%/<35%

4.3 Comercializacion

  • Carrusel 5 submodulos: LECHE (azul), CARNE (verde lima), COMPRADORES (purpura), CONTRATOS (purpura), TRANSPORTISTAS (rosa)
  • Wizard Venta Masiva 5 pasos completo: Aptitud -> Trazabilidad (ICA, Guia, Fitosanitaria) -> Economicos -> Liquidacion (comprador REGA, SEUROP) -> Logistica (transportista ATG, vet autorizador)
  • Post-venta: DIMOE auto, Movimiento oficial SIGGAN, Albaran PDF, Factura PDF, Estado VENDIDO
  • Compradores: Badges tipo Carnico (rojo), Lacteo (azul), Hibrido (verde lima)
  • Contratos: Multi-precio tabla, alertas vencimiento banner amarillo pulsing (CT-2026-001 15d)
  • Transportistas: Badges certificados Vigente/Proximo 30d/Caducado/Sin certificado

4.4 Informes & Sanidad

  • Informes: 5 categorias sidebar, 32 sub-tabs, 13 tipos graficas, KPIs semaforo 30+, Export PDF/Excel/CSV
  • Libros: Export Cuaderno Digital -> ZIP 8 CSV SIGGAN + README, pre-flight verde
