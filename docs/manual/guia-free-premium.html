Compra

2. Compra Premium (IAP Google Play)

2.1 Producto

  • ID: premium_unlock
  • Tipo: Compra unica (non-consumable / managed product)
  • Precio: Definido en Play Console (usuario decide)
  • Entrega: Inmediata tras verificación recibo

2.2 Flujo Compra

  1. Usuario pulsa "Activar Premium" en Ajustes > Cuenta
  2. App llama BillingClient.queryProductDetailsAsync()
  3. Lanza launchBillingFlow() -> Dialog Play Store
  4. Usuario confirma compra -> onPurchasesUpdated()
  5. App verifica firma + acknowledgePurchase()
  6. PremiumManager.setPremium(true) -> Persiste en Configuracion (IndexedDB)
  7. UI actualiza: Banner FREE oculto, limites desbloqueados, boton cambia a "Premium ACTIVO"

2.3 Restaurar Compras

  • Boton "Restaurar compras" en Ajustes > Cuenta
  • Llama BillingClient.queryPurchasesAsync()
  • Si encuentra premium_unlock owned -> setPremium(true)
  • Funciona tras reinstalacion / cambio dispositivo (misma cuenta Google)

2.4 Build Oficial Premium (Android)

  • Script: Private/build-and-upload.ps1
  • Genera variante FREE para Play Store (versionCode incremental)
  • El codigo Premium esta SIEMPRE en la app, se activa/desactiva por flag PremiumManager.isPremium()
  • No hay build separado "Premium" - misma APK, flag runtime

3. Implementacion Tecnica (PremiumManager)

3.1 API Principal

  • PremiumManager.isFree() -> !isPremium()
  • PremiumManager.isPremium() -> Lee config.premium === true (IndexedDB)
  • PremiumManager.setPremium(true/false) -> Persiste + EventBus 'premium:changed'
  • PremiumManager.getLimits() -> {fincas, animales, gastos} segun estado

3.2 Validaciones en Modelos (.save())

// Fincas.save()
if (PremiumManager.isFree() && await Fincas.count() >= 1) {
  throw new Error('Limite FREE: Max 1 finca. Activa Premium para mas.');
}

// Animales.save(fincaId)
if (PremiumManager.isFree() && await Animales.count(fincaId) >= 15) {
  throw new Error('Limite FREE: Max 15 animales/finca. Activa Premium.');
}

// Gastos.save(fincaId)
if (PremiumManager.isFree() && await Gastos.count(fincaId) >= 30) {
  throw new Error('Limite FREE: Max 30 gastos/finca. Activa Premium.');
}

3.3 UI Condicional

  • Banner FREE: v-if="PremiumManager.isFree()" en Ajustes, Dashboard
  • Botones "Nueva Finca": v-if="PremiumManager.isPremium()"
  • Export Excel/PDF Informes: v-if="PremiumManager.isPremium()"
  • Cuaderno Digital Export: v-if="PremiumManager.isPremium()"
  • Backup Auto: if (PremiumManager.isPremium()) scheduleBackup()
QA

4. PremiumQA.runAll() — Tests Automatizados

Suite de tests que verifica TODOS los limites en modelos, no en vistas:

  • test('FREE: bloquea 2da finca') -> Espera Error 'Limite FREE: Max 1 finca'
  • test('FREE: bloquea animal 16') -> Espera Error 'Limite FREE: Max 15 animales'
  • test('FREE: bloquea gasto 31') -> Espera Error 'Limite FREE: Max 30 gastos'
  • test('PREMIUM: permite fincas ilimitadas') -> Sin error
  • test('PREMIUM: permite animales ilimitados') -> Sin error
  • test('PREMIUM: permite gastos ilimitados') -> Sin error
  • test('Toggle FREE->PREMIUM desbloquea') -> setPremium(true) -> save OK
  • test('Toggle PREMIUM->FREE rebloquea') -> setPremium(false) -> save bloquea si exceso

Ejecutar: npm run test:premium o desde DevTools PremiumQA.runAll()

Edge Cases

5. Casos Limite & Preguntas Frecuentes

5.1 Si Usuario FREE tiene 15 animales y compra Premium

Compra -> setPremium(true) -> Inmediatamente puede añadir animal 16. No hay migracion de datos.

5.2 Si Usuario PREMIUM tiene 50 animales y vuelve a FREE (reembolso/cancelacion)

No se borran datos. Los 50 animales permanecen. Pero Animales.save() bloquea NUEVOS animales hasta bajar de 15. Usuario debe vender/dar baja para volver a crear.

5.3 Multi-dispositivo / Multi-sesion

Flag premium en Configuracion (IndexedDB) -> Sincroniza via backup/restore o export/import JSON. No usa cloud sync (futuro).

5.4 Version PWA / MSIX Desktop

  • PWA (livestock-manager.pages.dev): Gratis, sin IAP. PremiumManager.isPremium() siempre false en build FREE.
  • MSIX (Microsoft Store): Gratis hoy. Si app crece (SIGGAN), posible compra unica futura (no decidido).
  • Android (Play Store): Unica con IAP premium_unlock. Build FREE para publicar.
